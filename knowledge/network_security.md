# Network Security

Network security protects computer networks, devices, and data from unauthorized access, misuse, disruption, or modification. Secure networks normally use several layers of protection. # Authentication

Authentication verifies the identity of a user, device, or service. Examples include passwords, multi-factor authentication, certificates, and security tokens. # Authorization

Authorization determines which resources an authenticated identity may access. # Firewalls

A firewall controls network traffic according to security rules. It can inspect source addresses, destination addresses, ports, and protocols. Firewalls may run on hosts or dedicated network appliances. # Encryption

Encryption transforms readable information into a protected representation using an algorithm and key. Symmetric encryption uses the same secret key for encryption and decryption, while asymmetric cryptography uses public and private keys. # Intrusion Detection and Prevention

An Intrusion Detection System, or IDS, monitors network or system activity and generates alerts when suspicious behavior is detected. An Intrusion Prevention System, or IPS, can also block or limit detected malicious activity. # Common Network Threats

Common threats include phishing, malware, denial-of-service attacks, credential theft, spoofing, and unauthorized access. Security controls should be combined with user awareness, updates, monitoring, and suitable access policies. # Secure Communication

Protocols such as TLS provide cryptographic protection for application communication. Secure communication helps prevent attackers from reading or modifying information while it travels across an untrusted network. # Key Concepts

Network security combines authentication, authorization, encryption, traffic filtering, monitoring, and incident response. A layered security architecture reduces the impact of a compromised component. # Quick Reference

Concept Purpose Authentication Verify identity Authorization Control permitted access Firewall Filter network traffic Encryption Protect information from unauthorized reading IDS Detect suspicious activity IPS Detect and block suspicious activity TLS Protect communication using cryptography
