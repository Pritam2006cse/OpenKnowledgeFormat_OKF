# Okf Test Knowledge Network Security

## Page1

Network Security Fundamentals
A small technical knowledge source for testing OKF PDF-to-Markdown ingestion, indexing, and semantic
retrieval.
1. Introduction
Network security protects computer networks, devices, and data from unauthorized access, misuse, disruption,
or modification. Secure networks normally use several layers of protection.
2. Authentication and Authorization
Authentication verifies the identity of a user, device, or service. Examples include passwords, multi-factor
authentication, certificates, and security tokens. Authorization determines which resources an authenticated
identity may access.
3. Firewalls
A firewall controls network traffic according to security rules. It can inspect source addresses, destination
addresses, ports, and protocols. Firewalls may run on hosts or dedicated network appliances.
4. Encryption
Encryption transforms readable information into a protected representation using an algorithm and key.
Symmetric encryption uses the same secret key for encryption and decryption, while asymmetric cryptography
uses public and private keys.
5. Intrusion Detection and Prevention
An Intrusion Detection System, or IDS, monitors network or system activity and generates alerts when
suspicious behavior is detected. An Intrusion Prevention System, or IPS, can also block or limit detected
malicious activity.
6. Common Network Threats
Common threats include phishing, malware, denial-of-service attacks, credential theft, spoofing, and
unauthorized access. Security controls should be combined with user awareness, updates, monitoring, and
suitable access policies.
7. Secure Communication
Protocols such as TLS provide cryptographic protection for application communication. Secure communication
helps prevent attackers from reading or modifying information while it travels across an untrusted network.
8. Key Concepts
Network security combines authentication, authorization, encryption, traffic filtering, monitoring, and incident
response. A layered security architecture reduces the impact of a compromised component.
